# Dependency Graveyard

Дашборд для огляду застарілих залежностей і можливих альтернатив.

## Запуск

Потрібен Node.js 20.19+ або 22.12+.


## Поточні можливості

- Оглядова панель зі зведенням стану проєкту.
- Пошук, фільтрація за рівнем проблеми та сортування демонстраційного списку.
- Рекомендовані альтернативи й оцінка ризику для кожної залежності.
- Експорт демонстраційного звіту у CSV.
- Сканування маніфестів JavaScript / TypeScript, Python, Java, Go, Rust, PHP, Ruby, C# і C/C++.
- Пошук збігів із вбудованим каталогом демонстраційних застарілих пакетів.
- Окрема онлайн-перевірка поточної версії та дати публікації через публічні реєстри npm, PyPI, Maven Central, Go, crates.io, Packagist, RubyGems і NuGet.
- Окрема перевірка встановлених версій на відомі вразливості через базу OSV.
- Центр рекомендацій із причиною, застереженням щодо міграції, документацією та командами для ручного копіювання.
- Історія останніх 10 сканувань у localStorage з порівнянням нових і зниклих збігів.

Підтримувані файли: `package.json` і npm lock-файли, `requirements.txt`, `pyproject.toml`, `Pipfile` / `Pipfile.lock`, `pom.xml`, `build.gradle`, `go.mod`, `Cargo.toml` / `Cargo.lock`, `composer.json` / `composer.lock`, `Gemfile` / `Gemfile.lock`, `.csproj`, `packages.config`, `vcpkg.json`, `conanfile.txt`.

Розбір маніфестів відбувається локально у браузері. Онлайн-перевірка запускається окремо після підтвердження: до відповідного публічного реєстру надсилаються лише назви пакетів та встановлені версії; вміст файлів і код не передаються. Назви приватних пакетів можуть розкрити інформацію про проєкт. Для vcpkg та Conan онлайн-джерело поки не підключене.

Онлайн-реєстри надають версію та, де доступно, дату останньої публікації. Перевірка безпеки окремо надсилає назви пакетів, екосистеми та версії до OSV після підтвердження. OSV повертає advisories для конкретних версій через [batch API](https://google.github.io/osv.dev/post-v1-querybatch/). Центр рекомендацій використовує кураторську таблицю для відомих пакетів; невідомим залежностям заміна не вигадується. Команди лише копіюються й не запускаються сайтом. Оцінка ризику поки є локальною демонстраційною оцінкою; відсутність advisories не підтверджує, що пакет безпечний.

Історія перевірок зберігає назви пакетів, версії та підсумки лише у localStorage цього браузера (до 10 сканувань). Вміст маніфестів не зберігається й історія не синхронізується між пристроями.
